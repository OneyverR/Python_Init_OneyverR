## Cómo resolverlos

1. Abre el archivo `reto_XX_*.py` y lee el enunciado (está en el docstring de arriba).
2. Completa la función donde dice `# TODO`.
3. Corre los tests:

```bash
pytest retos/01_fundamentos -v
```

Cuando los 4 tests de cada reto estén en **verde**, lo has superado. ✅

> Empiezan en rojo porque las funciones aún devuelven `None`. Ese es el punto de partida.
