## Cómo resolverlos

1. Abre el archivo `reto_XX_*.py` y lee el enunciado (está en el docstring de arriba).
2. Completa las variables donde dice `# TODO` (reemplaza el `None` por tu solución).
3. Corre los tests:

```bash
pytest retos/01_fundamentos -v
```

Cuando todos los tests de cada reto estén en **verde**, lo has superado. ✅

> Empiezan en rojo porque las variables valen `None`. Ese es el punto de partida.
