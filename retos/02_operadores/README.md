# Retos — 02 Operadores, booleanos y texto

Refuerzan los temas de tu avance reciente: **operadores aritméticos, comparaciones,
booleanos (`bool()`), None, y más texto (slicing, `replace`, `split`)**.
(Sigue sin funciones ni `if`/`for` — eso llega en su módulo.)

| Reto | Archivo | Concepto |
|------|---------|----------|
| 04 | `reto_04_operadores.py` | Operadores `//`, `%` y comparación |
| 05 | `reto_05_booleanos.py` | Comparaciones y `bool()` |
| 06 | `reto_06_slicing.py` | Índices y slicing de texto |
| 07 | `reto_07_replace_split.py` | `replace()` y `split()` |

## Cómo resolverlos

1. Abre el archivo `reto_XX_*.py` y lee el enunciado (docstring de arriba).
2. Reemplaza el `None` de cada variable por tu solución.
3. Corre los tests:

```bash
pytest retos/02_operadores -v
```

> Empiezan en rojo porque las variables valen `None`. Ese es el punto de partida.
> ¿Curioso? Ese `None` que reemplazas es justo el tema que viste en `None.py`. 😉
