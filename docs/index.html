Bloque 1 — Fundamentos

Resuelve cada reto en su archivo .py y pon los tests en verde con pytest. Los tests que debe pasar tu solución están abajo.

01

Asignación múltiple

variables
Partiendo de a = 5 y b = 9, crea las variables a_nuevo y b_nuevo con los valores intercambiados, usando asignación múltiple en una sola línea.
📄 retos/01_fundamentos/reto_01_variables.py
Ver tests que debe pasar 
a_nuevo == 9    # el valor que tenía b
b_nuevo == 5    # el valor que tenía a
02

Conversión de tipos

tipos
Dados precio_texto = "1500", flotante = 9.99 y entero = 7, crea las conversiones pedidas. Recuerda: int() sobre un flotante trunca el decimal, no redondea.
📄 retos/01_fundamentos/reto_02_tipos.py
Ver tests que debe pasar 
precio_entero      == 1500   # texto -> entero
flotante_truncado  == 9      # 9.99 -> 9 (trunca, no redondea)
entero_flotante    == 7.0    # entero -> flotante
03

Métodos de strings

strings
Dados usuario_crudo = " Oneyver_Dev " y una frase, crea: usuario (limpio y en minúsculas), longitud (nº de caracteres) y tiene_python (si contiene la palabra "Python").
📄 retos/01_fundamentos/reto_03_texto.py
Ver tests que debe pasar 
usuario       == "oneyver_dev"
longitud      == 28
tiene_python  == True
